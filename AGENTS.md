# Инструкции для подпроекта Fusion Common

## Контроль качества и команды разработки

Все команды выполняются из корня подпроекта `projects/fusion-common`:

- Обязательные проверки качества:
  - `uv run ruff check . --fix`
  - `PYTHONUTF8=1 uv run mypy . --pretty`
  - `uv run vulture`
  - `uv run pytest`

## Архитектурные правила

1. Пакет `fusion_common` представляет собой чистое функциональное и сериализационное ядро (`Functional Core`) без зависимостей от GUI (`PySide6`), аппаратных портов (`pyserial`) или тяжёлых библиотек компьютерного зрения (`opencv`).
2. Формат `.fus` (v2.0) следует принципу открытости/закрытости (OCP): датчики (`sensor`), компенсация холодного спая (`cjc`), калибровки (`calibration`) и специфичные атрибуты (`metadata`, например `exo_up`) привязаны к конкретному каналу `ChannelDescriptor`, а не к корню манифеста.
3. Загрузчик `load_measurement` обязан сохранять 100%-ную обратную совместимость со всеми архивными форматами (`.tda`, `.vtaz` v0.0 и v1.0, `.fus-mdt` v1.0, `.fus-fmdt` v1.0).
