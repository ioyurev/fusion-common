# Fusion Common

Общая библиотека доменных моделей, эталонных термопар ГОСТ Р 8.585-2001, калибровок температуры, файловых кодеков и сборочных утилит для экосистемы термического анализа **Fusion** (`fusion-collection`, `fusion-analysis`).

## Возможности

- **По-канальная архитектура контейнеров `.fus` и `.fusa` (v1.0):** разделение неприкосновенных файлов сырых измерений (`.fus`) и файлов результатов анализа (`.fusa`) с поддержкой произвольного числа термопар и каналов.
- **Полиморфные модели термопар по ГОСТ Р 8.585-2001 (`SensorSpec`):** встроенный справочник всех 12 стандартных типов термопар ГОСТ Р 8.585-2001 (включая ТВР А-1/А-2/А-3, трёхдиапазонную ТХА K, ТПП S/R, ТПР B, ТНН N, ТЖК J, ТХКн E, ТМК T, ТХК L) и менеджер пользовательских термопар `ThermocoupleManager`.
- **Калибровки температуры (`CalibrationSpec` и `CalibrationManager`):** аддитивные полиномиальные калибровки по стандартным образцам со статистикой ($R^2$, $\text{SEC}$, $U = 2\cdot\text{SEC}$), прямые полиномиальные и таблично-сплайновые калибровки.
- **Обратная совместимость чтения:** прозрачное чтение архивных файлов `.tda`, `.vtaz` (v0.0 и v1.0), `.fus-mdt` (v1.0) и `.fus-fmdt` (v1.0) через открытый реестр `FORMAT_LOADERS`.

## Требования и проверка

- Python >= 3.13, менеджер пакетов `uv`
- Запуск тестов: `uv run pytest`
