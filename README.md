# Fusion Common

Общая библиотека доменных моделей, термометрии, калибровок температуры и файловых кодеков для экосистемы термического анализа **Fusion** (`fusion-collection`, `fusion-analysis`).

## Возможности

- **По-канальная архитектура измерений (`.fus` v2.0):** поддержка произвольного числа термопар и аналитических каналов в одном измерении.
- **Полиморфные модели термопар и датчиков (`SensorSpec`):** полиномиальные (включая встроенные пресеты ВР и ХА), кусочно-полиномиальные и таблично-сплайновые градуировки, менеджер пользовательских термопар `ThermocoupleManager`.
- **Полиморфные калибровки температуры (`CalibrationSpec`):** аддитивные полиномиальные калибровки по стандартным образцам со статистикой ($R^2$, $\text{SEC}$, $U = 2\cdot\text{SEC}$), прямые полиномиальные и таблично-сплайновые калибровки.
- **Полная обратная совместимость:** прозрачное чтение исторических файлов `.tda`, `.vtaz` (v0.0 и v1.0), `.fus-mdt` (v1.0) и `.fus-fmdt` (v1.0).
